# Sales Data Analysis using Python, SQL, and Power BI

## Project Overview
This project focuses on analyzing sales data using Python, SQL, and Power BI to generate business insights and interactive visualizations.

The project demonstrates the complete data analytics workflow including:
- Data cleaning
- Data transformation
- Database integration
- Dashboard creation
- Business insights generation

---

## Tools & Technologies Used
- Python
- Pandas
- SQLAlchemy
- MySQL
- Power BI
- Excel

---

## Project Workflow

### 1. Data Cleaning using Python
- Imported raw Excel sales dataset
- Removed rows with null date values
- Cleaned and transformed data using Pandas
- Prepared data for database storage

### 2. Database Integration using SQL
- Connected Python with MySQL using SQLAlchemy
- Uploaded cleaned data into MySQL database
- Managed structured sales data for analysis

### 3. Data Visualization using Power BI
Created interactive dashboards to analyze:
- Monthly Sales Growth
- Profit by Region
- Product-wise Sales Performance
- Overall Sales & Profit KPIs

---

## Key Insights
- Identified monthly sales trends
- Compared profit performance across regions
- Analyzed top-performing products
- Evaluated overall business growth
